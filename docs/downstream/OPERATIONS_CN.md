# A 股模拟账户的持续运行与观测

[English](OPERATIONS.md) · [页面运行指南](WEB_WORKSPACE_CN.md)

本模块只管理虚拟资金与模拟成交，不连接真实券商，不批准每日规则，也不自动晋级策略。HTTP 服务处理人工请求；独立 `app.ashare.managed_worker` 持有 PostgreSQL 全局和账户所有权锁，轮询行情、撮合并维护运行记录。

## 进程健康与交易就绪是两个状态

```bash
python -m app.ashare.healthcheck --max-age-seconds 120
```

退出码 0 代表数据库可访问、worker 心跳未过期且进程仍运行；退出码 1 代表数据库/结构不可用、未见心跳、心跳过期/来自未来或进程已停止。JSON 输出不包含数据库地址和密码。空账户列表仍产生心跳；每个账户开始前和整个循环完成后都会更新，避免把正常账户处理误认为停机。正常退出写入 `stopped`；异常断电由心跳过期识别。

午休、休市、待人工审核、行情拒绝、磁盘不足和账本对账错误都可能在**进程健康**时出现。健康检查不授予下单权限，也不把这些业务状态当作需要不断重启的进程故障。页面/API 继续使用独立的报价时效、规则日期、账户状态与交易时段检查。

worker 保持数据库断线退避重连（1、2、4…最多 30 秒），SIGTERM/SIGINT 请求在当前有界外部调用结束后停止。正常循环日志只在账户状态变化或每 60 秒输出一次；仍应由部署层轮转日志。

## 日终、日报与账本对账

交易日收盘后，worker 释放当日尚未成交的 DAY 委托及其剩余冻结资金；次日启动仍会释放此前遗留委托，不依赖新的成功行情请求。收盘前的最后三分钟继续按不支持的集合竞价处理，不撮合。

日报以 `(tenant_id, account_id, trading_day)` 为唯一键写入 PostgreSQL，并记录生成审计事件。重启不重复生成或覆盖。离线后每轮最多补扫 31 个自然日期，仅为日历确认的交易日生成报告；起点为首次观测日期或已有实际委托的更早日期。未知日历区间停止补扫，绝不猜测未来休市安排。

报告中的 `cash_end`、`positions_end`、当日成交额/费用由当日及以前的持久化成交重新计算，不使用当前持仓冒充历史收盘持仓。`late_generation` 标明补生成。没有可信收盘价时 `equity_end` 为 `null`，不编造净值、收益率或盈亏。报告对账的范围明确为生成时的整个账本。

每轮处理前用数据库聚合核对现金、股份、每单成交数量/金额/费用和冻结资金。发现差异进入 `reconciliation_failed`，停止采集及撮合；下一轮仍核对真实账本，仅在实际差异修复后恢复。系统不会自动改写资金或删除审计来“修好”差异。日报、后台对账及接口查询均保持用户隔离。

## 自然运行与受控回放证据

每次真正的轮询尝试都会更新当日观测统计，记录最早/最晚采样时间、轮询总数、失败次数、就绪次数、旧/未来时间报价次数、最大源时间年龄，以及最近一批报价的源时间和原始证据哈希。自然时钟与测试注入时钟分别计入 `wall_clock_polls` 和 `controlled_time_polls`。

日报包含生成时的 `observation_summary`。未观察过的补报日期明确为 `not_observed`；记录了样本也只标为 `sampled_not_continuous_uptime_proof`。样本首尾时间和计数不能证明期间从未断线，跨日期回放不能替代自然运行多个交易日。最大源时间年龄也不是网络延迟测量，休市报价自然变旧会计入。

实际连续多日验收应保留日报、轮转后的服务日志、数据库备份及原始行情证据，逐日核对自然时钟样本、失败/过期情况和持仓/资金变化。当天的盘中统计仍可变化；已生成日报不回写后续样本。

## 存储与采集频率

连续竞价按账户配置间隔轮询；午休和盘前至少间隔 60 秒，收盘、非交易日及未知日历至少间隔 300 秒，心跳继续更新。恢复连续竞价后立即使用正常配置间隔。

`ASHARE_MIN_FREE_DISK_BYTES` 默认 `104857600`（100 MiB），检查原始证据目录所在文件系统。低于阈值时进入 `storage_low`，暂停采集及撮合；释放空间后复验并恢复。系统不自动删除原始证据。该检查不代替 PostgreSQL 所在卷的容量告警；数据库、备份、WAL 和日志容量应由部署监控负责。

归档前先做校验及可恢复备份。历史日报、审计和成交引用的证据需一并保存；不得只删除旧目录而保留无法追溯的哈希。当前单 worker 顺序处理账户，未宣称大规模账户低延迟 SLA，也未宣称日历范围之外能够继续撮合。
