## 实际浏览器链路

本地专用测试数据库与生成的验收账户，通过官方登录页进入 **A 股模拟**，未伪造前端登录态：

1. 初始化 100,000 元虚拟资金，页面显示真实平安银行报价及源时间/接收时间。
2. 填写工程验收来源说明，人工勾选并提交当日规则；数据库记录审批人、时间、原始报价哈希和审计事件。该测试说明明确未作交易所级证券状态认证。
3. 页面提交限价 12.30 元、100 股的虚拟买单，先冻结 1,235.01 元；随后真实盘中卖一报价触发 12.20 元成交，费用 5.01 元，现金变为 98,774.99 元，持仓 100 股。
4. 页面尝试当日卖出 100 股，被 T+1 拒绝，持仓不变。
5. 提交 11.07 元的不触价买单，冻结 1,112.01 元；点击撤单后资金释放，仍只有一笔成交。
6. 打开飞书页签验证三步引导、密码式输入、未配置状态、测试消息入口。未提供真实 Webhook，未发送真实群消息。

## 故障与时段演练

实际停止并恢复专用 PostgreSQL 容器。首轮发现官方认证将连接故障当作 token 失效，已修复并增加回归测试。修复后再次演练：页面保留原有效会话，旧报价变为过期、下单禁用；数据库恢复后 API 与 worker 自动恢复，页面无需重新登录，资金、持仓和成交数量不变。

持续运行实际跨过北京时间 11:30，worker 自动变为 `lunch`，停止撮合。跨日规则过期、旧挂单释放、节假日和日历越界通过受控时间测试验证；不是已经自然运行多个交易日或观察下午恢复。

浏览器同时发现并修复了暗色帮助文字不可读、刷新时本地时钟滞后导致状态闪烁，以及服务错误直接显示代码的问题。最终截图、账户状态 JSON、日志与 JUnit 结果保存在本机 `work/quantdinger-ui-acceptance/`，秘密配置不提交 Git。

## 保留边界

- 禁止真实券商及 AI 自动晋级，Agent Gateway 仍只读；页面操作只写虚拟账本。
- 当前日历仅覆盖至 2026-12-31，超界拒绝交易；每日证券状态仍需人审。
- 尚未支持公司行动、集合竞价、科创板/北交所及零股；未将任意 Strategy V2 自动部署到新账本。
- 网页报价不承诺交易所级实时 SLA，快照盘口模拟不保证真实排队成交。
- 本地预览是开发/验收环境，长期运行仍需按运行指南配置正式服务管理与备份。
