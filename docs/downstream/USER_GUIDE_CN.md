# 个人用户使用教程：A 股真实行情与虚拟资金

[English](USER_GUIDE.md) · [页面说明](WEB_WORKSPACE_CN.md) · [部署](DEPLOYMENT_CN.md) · [持续检查](MONITORING_CN.md)

## 先准备什么

**当前 A 股模拟交易闭环不需要申请一堆 API，也不需要券商账户。**已部署的机器需要保持运行并能够访问行情网站。浏览器登录的是本机 QuantDinger 账户，与飞书、BaoStock 或券商登录无关。

| 项目 | 是否需要申请 | 当前用途 |
| --- | --- | --- |
| 本程序账户 | 使用部署时创建的账户；不要重复初始化已有资金账户 | 页面登录、隔离自己的虚拟账本 |
| 当前盘中行情 | 无须用户填写行情 API Key | 程序读取腾讯网页行情快照；显示来源时间与接收时间 |
| BaoStock 历史数据 | 当前默认客户端登录不传个人账号或 API Key | 按日期获取历史证券列表、日线与提供商报告的证券状态；服务访问失败时不能用猜测结果替代 |
| AKShare | 本项目使用的公开接口无须用户购买统一 API Key | 是访问公开来源的 Python 库，具体接口限制取决于原始数据源；不是一份覆盖所有网站的商业数据授权 |
| 飞书 | 可选：有权限的群内创建自定义机器人，取得 Webhook；建议签名校验 | 成交、运行状态与日报事件通知 |
| 模型 API | 当前手工模拟流程不需要 | 官方其他 AI 页面可能需要另配服务商密钥；这不代表 AI 研究已接入本 A 股账本 |
| SMTP 邮件 | 使用现有密码登录及“当前密码”修改方式时不需要 | 注册邮箱验证码、邮件找回等功能才需要 |
| 券商 API | 不需要，也不要配置 | 本分支禁止实盘与 AI 自动晋级 |

BaoStock 发布者的[快速入门](https://pypi.org/project/baostock/)使用不传个人凭据的 `bs.login()` 并提供免费历史数据。AKShare 官方说明其数据来自[公开财经网站和交易所等来源](https://akshare.akfamily.xyz/introduction.html)。免费可访问不等于交易所认证的实时行情、完整历史时点数据库或持续可用承诺。更换为需要商业许可的来源时，应另行确认授权与费用。

## 第一次使用

1. 打开本机的 `http://127.0.0.1:5177/#/ashare-paper` 并登录。首次部署的账号和初始密码由部署者保存在私有配置中；密码修改后以新密码为准。不要把密码或私有配置粘贴到聊天。
2. 在 **A 股模拟** 查看资金。只有尚未创建虚拟账户时才设置初始虚拟资金；已有账户继续使用原资金和持仓，不需要重建。
3. 在页面下方 **关注列表** 设置证券，例如 `sz.000001`，保存。首次使用保持少量证券；有持仓或挂单的证券不能直接移除。
4. 在 **盘中行情** 检查最新价、买卖一、行情时间、接收时间和状态。交易日连续竞价时应有新鲜报价。休市、午休、过期报价、等待审核均不等于程序崩溃；这些状态会限制撮合。
5. 使用 **审核规则** 确认当日状态、价格带和来源。若版本提供 **批量审核当日规则**，可查看预填证据并逐项确认；数据未知、缺失或不属于当日时仍须补充可信资料，不能把昨日收盘状态直接批准为今天。
6. 填入买卖方向、100 股整手数量、限价，核对确认框后提交 **模拟委托**。买单先冻结虚拟资金，后续新鲜报价才可能成交，提交成功不保证成交。当日买入股份遵循 T+1，未成交部分可撤单。
7. 在下方 **委托、成交、持仓、每日账本** 检查结果。日报中的现金、费用和成交来自实际虚拟账本；缺少可信收盘估值时不会补造收益率。

## 每天怎样操作

开盘前或开始使用时确认后台健康、关注证券和当天状态来源；到连续竞价阶段确认行情新鲜，再审核当天规则。审核不会自动沿用昨天，也不会自动同意。历史状态、IPO/重新上市、除权等未知信息需要继续人工核验。

盘中提交委托后，独立 worker 继续采集与撮合，关闭浏览器不等于停止 worker。但必须保持部署主机、电源、网络、Docker 与数据磁盘正常。收盘后未成交的 DAY 委托过期释放冻结资金，并生成每日报告。次日仍需要当日规则确认。

支持范围见[页面说明](WEB_WORKSPACE_CN.md)；集合竞价、部分板块、零股及公司行动等未完成能力不能通过手工勾选解禁。当前真实行情是网页快照，无法保证与东方财富模拟盘或真实交易所队列逐笔一致。

## 飞书接入

在**电脑桌面版飞书**目标群中选择 **设置 → 群机器人 → 添加机器人 → 自定义机器人**，复制 Webhook；启用签名校验时同时复制签名密钥。移动端没有自定义机器人的添加入口，详见[官方群机器人说明](https://www.feishu.cn/hc/zh-CN/articles/360024984973-在群组中使用机器人)。个人用户需实际具备该群的添加权限。

回到 A 股模拟页面，选择 **飞书推送**；旧布局需滚动至下方页签。填入地址和密钥，保存后由你主动点击 **发送测试消息** 并检查群内是否收到。若启用了关键词校验，允许关键词 `模拟交易`。不要把 Webhook 提交到 Git 或聊天。

当前飞书是单向通知，不能在群里下单，也不执行策略审批。显示“已配置”代表已保存，实际送达需测试。后续更完整的通知、审批与行业研究属于单独验收项目。

配置后，新生成的每日账本会触发一条摘要：当天成交笔数、买卖金额、费用、期末现金、持仓与对账结果，并标明关注列表。尚无可信收盘估值时，净值、盈亏和收益率明确显示不可用，现金余额不冒充收益。AI 推荐和策略更新尚未接入时也会如实标注。消息数量/长度受限时显示截断提示，完整逐笔交易和证据在页面查看。已生成的旧日报不会因重新配置机器人而补发；网络结果不确定时不自动重试，以免重复送达。

## 尚不能按完整产品使用的部分

页面若提供 AI、机器人、新能源、半导体、跟随当下热点或自定义方向等选项，目前保存的是研究偏好。勾选主题不会立即启动资讯采集、推荐或自动买卖。

当前模拟闭环不要求 Jev 或 DeepSeek。未来使用 DeepSeek 生成式 API 需要单独的模型服务密钥；Laya 的本地模型路线需要下载并运行模型、接入本地授权与校准，并非换一个 URL 即可使用，也不是通过 DeepSeek API 执行。当前没有部署 Laya 模型权重或可用网关，具体接入状态见[决策服务调研](research/DECISION_PROVIDERS_CN.md)。

“选定行业 → 自动采集资讯 → AI 推荐股票 → 自动模拟买卖 → 更新策略”是后续目标，当前教程不把它当成已经交付的流程。资讯源接入与时间追溯、行业主题选择、推荐证据、预先批准策略的自动模拟执行和人工批准策略更新仍需分别实现与验收。AI 不能自行升级或晋级策略。当前可用的主要入口是人工确认规则、手工虚拟委托和后台持续行情撮合。

自然多个交易日运行仍需真实时间积累。[监测工具](MONITORING_CN.md)会报告已观测日期、故障和未完成验收项，不能通过增加合成测试次数把剩余待办变成“全部完成”。

资讯时间说明：官方研究采集器保留供应商返回的发布时间，缺失时留空，并单独记录 UTC 接收时间。研究报告不会把缺失或无法解析发布时间的资讯当作新鲜证据。搜索结果日期仍不是原站发布时间认证；目前尚未完成 A 股定时资讯原文归档与哈希追溯。

在 A 股模拟页面的“主题成分”页签，可选择已归档板块并查看成员、采集时间和原始证据哈希。截至 2026 年 11 月 18 日凌晨，人工智能、机器人概念、新能源各有一次真实回执；打开该页签或点击“刷新归档视图”即可查看新增选项。它们是采集时观测到的成分，不是实时行情或历史认证名单。查看或刷新不会采集新行情、修改关注列表或发起买卖；研究方向选项仍是偏好，定时资讯与自动研究尚需接入。详见[主题说明](THEMES_CN.md)。
