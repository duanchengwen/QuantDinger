# 个人用户使用教程：A 股真实行情与虚拟资金

[English](USER_GUIDE.md) · [页面说明](WEB_WORKSPACE_CN.md) · [部署](DEPLOYMENT_CN.md) · [持续检查](MONITORING_CN.md)

## 先准备什么

**当前 A 股模拟交易闭环不需要申请一堆 API，也不需要券商账户。**已部署的机器需要保持运行并能够访问行情网站。浏览器登录的是本机 QuantDinger 账户，与飞书、BaoStock 或券商登录无关。

| 项目 | 是否需要申请 | 当前用途 |
| --- | --- | --- |
| 本程序账户 | 使用部署时创建的账户；不要重复初始化已有资金账户 | 页面登录、隔离自己的虚拟账本 |
| 当前盘中行情 | 无须用户填写行情 API Key | 程序读取腾讯网页行情快照；显示来源时间与接收时间 |
| BaoStock 历史数据 | 当前默认客户端登录不传个人账号或 API Key | 按日期获取历史证券列表、日线与提供商报告的证券状态；服务访问失败时不能用猜测结果替代 |
| AKShare | 本项目使用的公开接口无须用户购买统一 API Key | 是访问公开来源的 Python 库，具体接口限制取决于原始数据源；不是一份覆盖所有网站的商业数据授权 |
| 飞书 | 可选：有权限的群内创建自定义机器人，取得 Webhook；建议签名校验 | 成交、运行状态与日报事件通知 |
| 模型 API | 当前手工模拟流程不需要 | 可选研究面板使用另行配置的 DeepSeek 密钥；不会因此获得交易权限 |
| SMTP 邮件 | 使用现有密码登录及“当前密码”修改方式时不需要 | 注册邮箱验证码、邮件找回等功能才需要 |
| 券商 API | 不需要，也不要配置 | 本分支禁止实盘与 AI 自动晋级 |

BaoStock 发布者的[快速入门](https://pypi.org/project/baostock/)使用不传个人凭据的 `bs.login()` 并提供免费历史数据。AKShare 官方说明其数据来自[公开财经网站和交易所等来源](https://akshare.akfamily.xyz/introduction.html)。免费可访问不等于交易所认证的实时行情、完整历史时点数据库或持续可用承诺。更换为需要商业许可的来源时，应另行确认授权与费用。

## 第一次使用

1. 打开本机的 `http://127.0.0.1:5177/#/ashare-paper` 并登录。首次部署的账号和初始密码由部署者保存在私有配置中；密码修改后以新密码为准。不要把密码或私有配置粘贴到聊天。
2. 在 **A 股模拟** 查看资金。只有尚未创建虚拟账户时才设置初始虚拟资金；已有账户继续使用原资金和持仓，不需要重建。
3. 在页面下方 **关注列表** 设置证券，例如 `sz.000001`，保存。首次使用保持少量证券；有持仓或挂单的证券不能直接移除。
4. 在 **盘中行情** 检查最新价、买卖一、行情时间、接收时间和状态。交易日连续竞价时应有新鲜报价。休市、午休、过期报价、等待审核均不等于程序崩溃；这些状态会限制撮合。
5. 使用 **审核规则** 确认当日状态、价格带和来源。若版本提供 **批量审核当日规则**，可查看预填证据并逐项确认；数据未知、缺失或不属于当日时仍须补充可信资料，不能把昨日收盘状态直接批准为今天。
6. 填入买卖方向、100 股整手数量、限价，核对确认框后提交 **模拟委托**。买单先冻结虚拟资金，后续新鲜报价才可能成交，提交成功不保证成交。当日买入股份遵循 T+1，未成交部分可撤单。
7. 在下方 **委托、成交、持仓、每日账本** 检查结果。日报中的现金、费用和成交来自实际虚拟账本；缺少可信收盘估值时不会补造收益率。

## 每天怎样操作

开盘前或开始使用时确认后台健康、关注证券和当天状态来源；到连续竞价阶段确认行情新鲜，再审核当天规则。审核不会自动沿用昨天，也不会自动同意。历史状态、IPO/重新上市、除权等未知信息需要继续人工核验。

盘中提交委托后，独立 worker 继续采集与撮合，关闭浏览器不等于停止 worker。但必须保持部署主机、电源、网络、Docker 与数据磁盘正常。收盘后未成交的 DAY 委托过期释放冻结资金，并生成每日报告。次日仍需要当日规则确认。

支持范围见[页面说明](WEB_WORKSPACE_CN.md)；集合竞价、部分板块、零股及公司行动等未完成能力不能通过手工勾选解禁。当前真实行情是网页快照，无法保证与东方财富模拟盘或真实交易所队列逐笔一致。

## 飞书接入

在**电脑桌面版飞书**目标群中选择 **设置 → 群机器人 → 添加机器人 → 自定义机器人**，复制 Webhook；启用签名校验时同时复制签名密钥。移动端没有自定义机器人的添加入口，详见[官方群机器人说明](https://www.feishu.cn/hc/zh-CN/articles/360024984973-在群组中使用机器人)。个人用户需实际具备该群的添加权限。

回到 A 股模拟页面，选择 **飞书推送**；旧布局需滚动至下方页签。填入地址和密钥，保存后由你主动点击 **发送测试消息** 并检查群内是否收到。若启用了关键词校验，允许关键词 `模拟交易`。不要把 Webhook 提交到 Git 或聊天。

飞书自定义机器人发送单向通知。管理员在运行配置中设置 `ASHARE_REVIEW_BASE_URL` 为审批页的 HTTPS 地址后，已配置 Webhook 的账户保存新策略草稿会收到「查看待批策略」卡片。按钮打开具体版本，用户登录后批准，并可另行启用自动模拟委托。一次草稿最多尝试发送一张卡片。实际送达以飞书群内看到的卡片为准。

配置后，新生成的每日账本会触发一条摘要：当天成交笔数、买卖金额、费用、期末现金、持仓与对账结果，并标明关注列表。尚无可信收盘估值时，净值、盈亏和收益率明确显示不可用，现金余额不冒充收益。日报缺少选股或策略更新数据时会直接标明。事件时间按北京时间显示。消息数量/长度受限时显示截断提示，完整逐笔交易和证据在页面查看。已生成的旧日报不会因重新配置机器人而补发；网络结果不确定时不自动重试，以免重复送达。

获批 10 分钟后仍未启用，系统会提醒一次并打开具体版本。已启用但因缺少当日人工证券审核而无法委托时，系统在有合格盘中行情的情况下提醒核对状态和价格带。每个版本每个交易日最多尝试一次审核提醒。

新模拟成交会单独推送，显示北京时间、买卖方向、证券、股数、成交价、成交额和费用。服务记录成交编号和发送回执。日报与成交通知可分别生成；旧记录按原有回执显示。

打开 **A 股模拟 → 每日账本**，查看「飞书回执」列。Webhook 已确认表示飞书接口已接受摘要，群内实际显示还需在飞书中查看。「送达结果未知」会保留原记录，旧日报显示「未记录回执」。

## 尚不能按完整产品使用的部分

页面若提供 AI、机器人、新能源、半导体、跟随当下热点或自定义方向等选项，目前保存的是研究偏好。勾选主题不会立即启动资讯采集、推荐或自动买卖。

当前模拟闭环不要求 Jev 或 DeepSeek。可选的公告研究面板使用单独配置的 DeepSeek 密钥和受支持模型，配置和证据限制见[研究说明](RESEARCH_CN.md)。Laya 的本地模型路线需要下载并运行模型、接入本地授权与校准，当前没有部署相关模型权重或可用网关。接入状态见[决策服务调研](research/DECISION_PROVIDERS_CN.md)。

本版本已实现有限公告采集、账户隔离研究队列和带证据引用的候选。定时研究可按操作员模板生成待审草稿。综合行业资讯、样本外评估和策略迭代仍待实现与验收。策略生效须由你批准。

本机已部署“策略版本”页签。打开 **A 股模拟 → 策略版本**，保存单次买入规则草稿，核对标的、触发价、限价、股数和含费资金上限，再批准或撤销具体版本。确认时会绑定版本编号与参数 SHA-256。账户同时只能批准一个版本，修改参数须建新版本。批准后另行确认“启用自动模拟委托”。后台须取得晚于启用与当日人工规则审核的新鲜行情，且含费冻结金额在版本上限和可用资金范围内，才会为该版本提交最多一笔模拟买单。撤销时取消未成交部分并释放对应冻结资金，已成交部分保留。上线时策略列表为空，实际用户启用与盘中触发仍待验收。见[本机部署验证](SECURITIES_ACCEPTANCE_CN.md)。

### 模拟买卖设置

打开 **A 股模拟** 顶部的 **模拟买卖设置**。范围可选当前自选，或指定其中的股票。填写单笔含费上限并保存启用。系统根据可核验的历史趋势和已结算虚拟持仓决定一手买入、卖出或观望。触发价和限价来自上一完整交易日的收盘价，在待审版本中可见。已有手填价格的模板保留范围和额度，新逻辑须由你重新启用。

定时任务只使用当天已完成且有调度记录的研究。系统先校验决策日前连续 60 个交易日的 BaoStock 未复权日线，前 20 日热身，后 40 日回放固定规则。用下一交易日的保守限价条件模拟成交，计算交易费用和 T+1。少于所需历史、缺日、来源不一致或没有有效信号时不会生成草稿。回测覆盖当前候选的固定规则；候选筛选本身未获得样本外验证。历史结果仅用于本次模拟策略审查。

每轮研究最多生成一份绑定原研究及不可变回测报告的草稿。草稿完成后通过飞书打开具体版本并核对方向、价位和回测。你逐版本批准、单独启用并完成人工证券审核。卖出只使用 T+1 可用股份；含费上限覆盖成交金额和费用，盘口价格变化也不能突破上限。停用模板会停止新草稿，已保存版本在其原页面管理。旧运维规则文件也须有精确匹配的回测才会出稿。

在 **资讯与研究** 的已完成结果中，已列入关注的候选可点击 **编写模拟策略草稿**。页面带入证券代码、研究编号和输入输出哈希，股数、触发价、限价和含费上限由你填写。保存后仍需逐版本批准、单独启用，并完成人工审核当天证券规则。新增委托前会再次核验关联研究。需要独立填写策略时，可以从 **策略版本** 开始，或在保存前移除研究依据。

**策略版本**详情显示预计含费冻结额和刷新时的可用资金。草稿保存、批准和启用时按模拟账户费率核算上限。上限不足时需要修改参数并保存为新草稿。可用资金可能随其他委托变化，后台提交委托时会按当时账本重新核验。

启用后，点击 **刷新** 可在版本详情查看该版本的自动模拟委托。触发前显示「尚无委托」。提交后显示委托编号、状态、已成交股数和金额、费用以及剩余冻结资金。部分成交后撤单或日终到期时，详情继续保留这笔委托的记录。

自然多个交易日运行仍需真实时间积累。[监测工具](MONITORING_CN.md)会报告已观测日期、故障和未完成验收项，不能通过增加合成测试次数把剩余待办变成“全部完成”。

资讯采集保留巨潮原始 JSON、PDF、供应商发布时间和 UTC 接收时间。缺失或无法解析发布时间的公告不会进入新鲜证据。本机队列已配置使用合格公告前 3 页的已校验节选，研究结果可区分只引用标题和包含节选。成功归档后，队列最多给正文提取两分钟的准备窗口，等下一轮计划任务检查。超过窗口仍缺少节选时可使用合格标题。完整行业资讯和首个使用节选的真实定时研究仍待验收。见[资讯验收](NEWS_RESEARCH_ACCEPTANCE_CN.md)。

展开已完成研究候选下方的公告标题，可查看该次研究实际引用的公告版本、原 PDF、发布时间和归档哈希。若该次研究使用了正文节选，也会显示当时传给模型的文本和对应哈希。相同公告的后续版本分别出现在资讯列表中。

在 A 股模拟页面的“主题成分”页签，可选择已归档板块并查看成员、采集时间和原始证据哈希。截至 2026 年 11 月 18 日凌晨，人工智能、机器人概念、新能源各有一次真实回执；打开该页签或点击“刷新归档视图”即可查看新增选项。它们是采集时观测到的成分，不是实时行情或历史认证名单。查看或刷新不会采集新行情、修改关注列表或发起买卖；研究方向选项仍是偏好，主动请求研究使用独立证据队列；定时采集和定时研究需要部署另行审查的日程。详见[主题说明](THEMES_CN.md)。

本机另已安装这三个主题的每日 20:10 采集任务，最多随机延后一分钟。失败会保留旧观测并记录问题，不把旧名单显示成新采集成功；同一晚失败或结果未知不会自动重试。安装和盘前跳过已验证，首次晚间自动采集仍待实际执行。它只更新主题资料，不会自动选股、批准策略或买卖。

2026-11-18 本机已部署“资讯与研究”页签并完成一次真实 DeepSeek 调用。打开 A 股模拟 → 资讯与研究 → 刷新，可查看公告和已有研究；无需再次提交研究来查看结果。本机已为现有授权账户安装每日 08:30 研究、每两分钟处理队列及 07:00–22:30 半小时公告采集。手工与定时研究共享每日最多 3 个新请求上限；它们均不会批准策略或自动下单。11 月 18 日 08:00 首次定时公告采集已归档并通过哈希验证。同日 08:30 首次定时研究已完成，结果和引用依据可在面板查看。详见[实际验收报告](NEWS_RESEARCH_ACCEPTANCE_CN.md)。
